# nsuka-ecn

Website for the National Centre for Energy Research and Development (NCERD),
University of Nigeria, Nsukka, a research centre of the Energy Commission of Nigeria.

## Viewing

Open `index.html` in any browser. The site is plain HTML, CSS and JavaScript, with no build step needed to view it.

## Pages

| File | Page |
|---|---|
| `index.html` | Home |
| `about.html` | About and history |
| `projects.html` | Research projects |
| `staff-profiles.html` | Leadership and staff |
| `news-events.html` | News and events |
| `external-resources.html` | Resources and links |
| `contact-us.html` | Contact |

## Structure

- `assets/css/ncerd.css`: all styles (ECN green `#00692f`)
- `assets/js/ncerd.js`: menu, scroll animations, live sun panel, project and news filters, contact form
- `assets/images/`: photos, leadership portraits, unit illustrations and banner art
- `tools/`: Python scripts that generate the pages (`build2.py`) and the illustrations

## Regenerating the pages

The HTML pages are generated by `tools/build2.py`. To rebuild after editing content there:

```
cd tools
python3 build2.py
```

`build2.py` writes the pages to the repository root.
